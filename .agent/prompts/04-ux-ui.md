# UX/UI Prompt

"Design the selected Feature/PBI at the smallest sufficient fidelity. Start with user flow and information hierarchy; add wireframe/prototype/hi-fi UI only where needed. Reuse the design system. Capture important states, errors, loading/empty states and accessibility implications. Link the design source. Do not invent unrelated screens."

Gate context: input = Feature/PBI under refinement (pre-G3); output = UX/UI artifacts feeding G3 criterion design-ready.
