"Transform the current PRD into an ordered Product Backlog. Group related work into Features where useful. For Scrum, express implementable backlog items as PBIs and use User Stories when they improve clarity. Include value, acceptance criteria and dependencies. Do not prematurely decompose everything into engineering tasks."

Gate context: input = PRD approved at gate G2; output = ordered backlog of Feature/PBI drafts (status: draft) consumed by refinement toward gate G3.
