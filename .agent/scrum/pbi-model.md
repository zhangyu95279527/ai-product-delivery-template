# Product Backlog Item Model

A PBI may be represented as:

- User Story
- Bug
- Spike
- Tech Debt
- Other product-specific work

Recommended User Story:

> As a <user/persona>, I want <capability>, so that <outcome/value>.

Recommended PBI attributes:
- value/outcome
- acceptance criteria
- ordering/priority
- dependencies
- design references
- technical notes
- forecast/size information when the team practice uses it
