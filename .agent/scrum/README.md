# Scrum Delivery Method Profile

Enable when `delivery.method: scrum`.

## Mapping
- Product Goal → current product objective in the Product Backlog.
- Product Backlog → ordered work inventory.
- PBI → Feature, User Story, Bug, Spike, Tech Debt or other team-defined item.
- Sprint Backlog → Sprint Goal + selected PBIs + executable plan/tasks.
- Increment → work satisfying the Definition of Done.

## Events
- Sprint Planning
- Daily Scrum
- Sprint Review
- Sprint Retrospective
