# Definition of Done — starter

Adapt this list to the actual product/team. Work is Done only when the shared quality bar is met.

- acceptance criteria verified
- code/design review completed as applicable
- automated tests passed
- required integration/E2E tests passed
- security checks passed where applicable
- observability completed where applicable
- documentation/contracts updated where applicable
- deployable/releasable artifact produced
- AI evaluation/guardrail checks passed for AI behavior where applicable
